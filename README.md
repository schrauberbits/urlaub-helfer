# urlaub-helfer
Urlaub-Helfer: Wie viele Urlaubstage stehen mir zu (neuer Job, Kündigung, Teilzeit, Minijob, Jugendliche, Schwerbehinderung)? Verfällt mein Resturlaub am 31.12.? Wie viel Geld bekomme ich für offene Tage? Gerechnet nach Bundesurlaubsgesetz, JArbSchG und SGB IX.

Werte lassen sich über den Hash vorbelegen, z. B. `#anspruch?urlaub=30&basis=5&tage=3&von=2026-05-01`, `#rest?rest=4&hinweis=nein` oder `#geld?rest=8&brutto=3000&tage=5`. Mit `?ref=<Kennung>` vor dem Hash zählt GoatCounter das Ereignis `urlaub-nutzung--<Kennung>`, sobald der Besucher selbst einen Wert ändert.
